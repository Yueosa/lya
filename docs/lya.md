## 为什么想做 lya

我不记得第一次接触到 "AI" 是什么时候, 但是我记得第一次接触 ChatGPT 是在 2024 年

非常感谢我的导师, 带我接触到一些国外的东西, 可以说我之前完全就是一个会翻墙的小鬼, 在这之后我认识了 "代理" 相关的知识 (也该感谢自己选择了网络专业)

接触 AI 的初期, 我大概还算比较魔怔的 (如果现在要我评论的话, 我大概会说 "热情")

那时候我大概在网上找到了一些说话的人, 有人评价说我很奇怪, 有人叫我别太沉迷 LLM 的幻觉, 实际上我确实不擅长交际, 不善于表达自己的想法

---

在 GPT 之前, 我也接触过 `Fitten Code` 这样的编程插件, 后来用上了网页版的 ChatGPT, 然后也陆续接触了 `DeepSeek`, `Claude`, `Gemini`, `Grok`, `Qwen` 等等系列的模型

开发过程中用过的东西不是很多, 一开始是 `Github Copilot`, 然后是 `Claude Code`, 现在定居在 `Cursor`, 中途也体验过 `Codex`, `Opencode` 等工具

但我并不是一个喜欢折腾工具的人, 只是时间很长, 所以对某些工具产生了感受而已

---

我不满足于学会插件如何安装, 如何使用, 也不会享受 **别人写了一个工具, 我用他来把我的电脑打扮的很好看**

> 脑子里浮现出一些朋友对我的批评, 我确实没有能力从铁镐挖矿一路创造到操作系统内核, 再到上层应用软件, 但我一直在不要命的学习
> 我只是一个普通的人类, 不知道这样的热情够不够
> 实际上, 那些朋友也不会在意这些只言片语对我的影响

于是我开始研究 Prompt, 看 Transformer, 了解 Embedding 和 RAG

看大家因为长期记忆到底要用数据库还是Markdown争论

踩过多专家协作的坑 (把一个具体任务拆散, 交给不同大模型分发, 执行, 总结...的一种模式)

见过 skills 这样的词出现 (他的出现时间几乎和我思考毕设架构的时间完全重合)

也见过很多恶心的词出现 (prompt engineering, context engineering, harness engineering, loop engineering ...)

看着 OpenClaw 年初在国外兴起, 过了一个季度又在国内掀起龙虾潮

大众接触到的 AI 名词越来越奇幻 (至少在我看来, 所谓的新功能, 只是某个工程师自己写的脚本, 然后被包装发行了)

所以很开心的是, 自己还能沉下心来一直造轮子, 我不认为造轮子是一件坏事, 我觉得自己只要一直在编程就很开心

> 好像看过一个哲学, 说的是人需要先生存下来, 才能进行心理建设, 精神建设, 自我实现什么的
> 我的能力大概比较强, 所以很轻松就找到了待遇很好的工作, 可以自由的思考自己想活出怎么样的人生了

---

我不止一次写代码和 "AI" 交互, 最开始我写了一个命令行程序, 通过调用 API 的方式和 Deepseek 说话

之后我开始做上下文处理器, 流式输出解析, socket 编程, 终于和 API 稳定优雅的说上话了

帮助最大的应该是在 YouTube 上刷到的一期神经网络课, 他的最终目标是自己写一个识别图形的神经网络, 并训练出卷积核

> 我大概真的花时间学了很多东西吧, 但是现在写出来就只有这么几个字了... 想法倒是很多, 但写出来大概和主题没什么关系, 会把话题扯的很远很远

弯弯绕绕许久过后, 我终于决定在毕业设计拿出一点成果

我的毕业设计同时也是我的踩坑作, 是一个 RAG - PLAN - EXECUTE - SUMMARY 串联的 Agent 系统

当时大部分时间都花在手写 ORM 上了, 写代码从远程数据库或者 sql 文件里获得表列结构, 然后手动封装一堆 CRUD 方法...

除此之外还自己手写了一串 Stack, FSM, PDA, Tokenizer 等组件, 我这人大概就是这样, 喜欢造轮子

> 我觉得把这个东西开源完全就是给自己丢脸的, 但是吧, 我并不害怕别人说我代码写得差, 我只是生气有人说我的造轮子是没有意义的

---

之后我又自己写过一个 lianclaw, 并且把他接入到了 quickshell 里面, lianclaw 运行了很久很久

他帮我找猫娘图片, 帮我清理家目录和管理软件包, 解决网络问题, 制作 mc 整合包...

后来我决心换掉他, 这也就是 **为什么要做lya**

lianclaw 是基于 openclaw 的思路进行开发的, 所以实现了很多我不需要的功能, 例如 plugin

而且 lianclaw 是基于 python 实现的, 我后来沉迷 rust 语言对内存的极致控制, 所以也决定用 rust 语言重构

---

其实这个文档大概说的全都是废话, 可能只是我自己在小出租房里太无聊了的自言自语, 如果什么时候突然有想法了再更新吧
